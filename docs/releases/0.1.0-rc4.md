# solo Private Beta Release 0.1.0-rc4

## Highlights

This release focuses on polishing some UI aspects and bug fixes. Thanks to everyone in the private beta for their help!

The main effort was on state handling across the whole app. This is not really visible to users, but it drastically improved performance and allowed us to have a more streamlined approach when developing.

### ✨ Features

#### 💅 UI

- Added middle-click handling on tabs to close them
- Replaced some text buttons with semantically correct icon buttons
- Added the collection name to the request breadcrumb on the request builder title
- Added click handling on collection title panels to collapse/toggle the contents
- Added right-click handling on requests in collections to open the context menu
- Added drag-and-drop to reorder requests inside collections
- Improved keyboard handling in the requests tab list
- Added About section in the app settings modal
- Improved UI for inputs where Environment variables are allowed
- Added different color and font highlights for variables:
  - Existing Env variables: primary + semibold
  - Existing Session variables: grey + semibold
  - Not existing variables: grey + italic
- Improved UI for importing Collections and Environments
- Added find&replace functionality to request and response bodies
- Added environment selection dropdown to quickly select the active environment
- Added Content-Type auto-resolution and soft-validation, showing warning if it's not right for the Body type

#### ⚙️ Backend

- Added Lua Scripting Engine Extensions:
  - `crypto` - supports MD5, SHA-1, SHA-256 and Base64 encoding/decoding
  - `uuid` - generation of UUID v4 strings
  - `time` - UNIX timestamps (seconds/ms) and date formatting via Go layouts
  - `yaml` - parsing and stringifying YAML data (parity with JSON/XML)
  - `utils` - URL encoding and decoding functions
- Added app version in logs
- Added version update notifications and download

### 🐞 Bug fixes

- Custom hosts TLS configuration now matches with the specified port number, falling back to matching hostname-only if an entry for `hostname:port` is missing
- User Agent override in requests is now respected
- Removed delay when opening context menus
- Fixed CPU usage spikes when editing Hosts TLS configurations
- Fixed graphic glitch when clicking on request tabs
- Fixed request builder's main input group appearance
- Use the same Environment variable popover component in Input elements and request's Body
- Fixed caret color in dark schemes for CodeMirror editors
- Collections Sidebar now has a minimum width
- Fixed radio button color in Environments modal
- Fixed variables resolution in pre-request scripts
