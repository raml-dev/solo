# Solo Release 0.1.0

## Highlights

This is the first release of `solo`! 🚀

We are excited to show our work and we want feedback!

The main features include:

- Basic HTTP requests
- Collections and Environments
- Lua scripting
- Import from OpenAPI documents, Postman, Bruno and curl
- Export collections to OpenAPI documents
- Git-based collaboration
- OAuth2 token retrieval and usage per-request
- Load testing with configurable iterations and concurrency
- Exportable request history

See more in our [docs website](https://solo.raml.workers.dev).

## Feedback

**We want your feedback!** Get in touch and report *anything* you think it's missing, not good, bugged, not working as expected, etc., opening a [GitHub issue](https://github.com/raml-dev/solo/issues/new/choose).

## Known issues

Binaries are not signed by either `codesign` or `signtool`. We will explore our options once we had a solid round of feedbacks and we built our initial user base.

This means that, for now, Windows and macOS users will have to do extra steps:

- macOS users:
  - Install the application either via `brew install solo` or by downloading the binary from the [releases page](https://github.com/raml-dev/solo/releases).
  - Try to open the application once. A message from macOS will show up saying that the application is from an untrusted developer.
  - Open a terminal and run `xattr -dr com.apple.quarantine /Applications/solo.app`, or open `System Settings` > `Privacy & Security` and click on `Open Anyway`.
- Windows users:
  - Install the application either via `scoop install solo` or by downloading the binary from the [releases page](https://github.com/raml-dev/solo/releases).
    > [!NOTE]
    >
    > After finishing the standalone binary download, some browsers (i.e.: Edge) may show a warning about the file not being downloaded often; there will be a menu option to keep the downloaded file.
  - When running `Solo` the first time, Windows may show a SmartScreen warning about this file not being signed by a trusted developer; click on "More info" and then "Execute anyway".
