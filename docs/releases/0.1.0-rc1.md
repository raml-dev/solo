# solo Private Beta Release 0.1.0-rc1

## Highlights

This is the first release of `solo`! 🚀

We are excited to show our work and we want feedback!

The main features include:

- Basic HTTP requests (well, it's an API client 😅)
- Collections and Environments
- Lua scripting
- Import from OpenAPI documents, Postman, Bruno and curl
- Git-based collaboration
- OAuth2 token retrieval and usage per-request
- Load testing with configurable iterations and concurrency
- Theming
- Exportable request history

## Installation

As this is an early beta release, binaries are not signed by either `codesign` or `signtool`. We will explore our options once we had a solid round of feedbacks and we built our initial user base.

This means that, for now, Windows and macOS users will have to do extra steps:

- macOS users:
  - Download the DMG for your architecture
  - Open the DMG and copy `solo` into Applications
  - Open a terminal and run `xattr -dr com.apple.quarantine /Applications/solo.app`
- Windows users:
  - Download the binary for your architecture
  - After finishing the download, some browsers (i.e.: Edge) may show a warning about the file not being downloaded often; there will be a menu option to keep the downloaded file
  - After executing `solo` the first time, Windows may show a SmartScreen warning about this file not being signed by a trusted developer; click on "More info" and then "Execute anyway"

Linux users just have to download the binary and run it. We will package the application properly in a future phase, including a Desktop entry and icons.

- The request body tab has the request type Select on top of its label
- The request body tab's text area shows a popover for environment variables when typing `{{` that is different from the one shown anywhere else
- The console URL input has different dimensions compared to the near Selects and Buttons
- The Response headers are not in a table format and there is no "Copy to clipboard" Button

- Overall, all Buttons, Inputs and Select elements need to be reviewed for consistent dimensions
- The button to collapse the Collections sidebar should be aligned to the right and it should be a transparent Icon button
- The "Import" and "New" buttons in the Environment manager should be aligned to the left
- The "..." button in the Environment manager's items should be a transparent Icon button

- The "No specific hosts found" message in the Hosts configuration pane is not full width
