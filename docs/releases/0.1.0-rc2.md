# solo Private Beta Release 0.1.0-rc2

## Highlights

This release focuses on stability and UX refinement, addressing initial bugs and improving the robustness of the backend.

Key updates include:

- **Host Configuration Fix**: Resolved the issue where custom TLS configuration fields would not appear immediately when toggled.
- **Improved File Management**: The collection folder is now automatically created on the first run, preventing errors during initial setup or imports.
- **WebView Stability**: Disabled the default WebView drag-and-drop behavior to prevent accidental navigation or unexpected behavior when interacting with the UI.
- **System Testing**: Introduced a comprehensive suite of unit tests for the filesystem (`fs`) module to ensure reliable data management.
- **CI/CD Refinement**: Optimized the release pipeline for better SHA256 checksum generation and handling of release candidate tags.
