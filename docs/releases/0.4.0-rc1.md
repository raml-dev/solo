# Solo release 0.4.0-rc1

## Highlights

This release candidate expands request authentication with native Bearer token support.

## ✨ New Features

- Rename the OAuth tab to Auth and present the available authentication methods as an extensible list.
- Add native Bearer token authentication with masked token input, visibility control, and mutually exclusive OAuth2 and Bearer modes.
- Encrypt stored Bearer tokens using the existing machine-specific encryption mechanism.
- Inject configured Bearer tokens into outgoing requests while preserving an explicitly configured `Authorization` header.
- Import authentication settings from Postman, Bruno, cURL, and OpenAPI collections.
- Export Bearer authentication as an OpenAPI security scheme.

# 🐞 Bug fixes

- Prevent authentication credentials from being exposed in response metadata and request history.
- Render authentication mode selection as radio buttons instead of toggle switches.
- Keep the environment picker in a modal instead of an anchored dropdown, and preserve centered modal placement.
- Preserve sidebar request highlighting when opening a request so the active tab is visually obvious.
- Keep the CodeMirror search UI in overlay mode for request and response editors instead of pushing content downward.
